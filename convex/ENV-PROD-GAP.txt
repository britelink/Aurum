Aurum Convex — environment
==========================

This file is now a pointer. The authoritative list, with what each variable is
for and what breaks without it, lives in `convex/RAILS.md` under "Environment".

To see what is already resolvable and what is missing:

    npm run env:plan                                    # dry run
    npm run env:plan -- --sgx ../chessa-main/.env.local  # pull from SGX too
    npm run env:apply                                   # set it on dev
    node scripts/seed-convex-env.mjs --apply --prod     # set it on production

`scripts/seed-convex-env.mjs` knows the old SGX/Penny names and maps them onto
the ones the code reads today (`PRIVATE_KEY` → `AURUM_AGENT_PRIVATE_KEY`, and so
on), generates the Convex Auth key pair if either half is missing, and refuses
to apply a partial rail configuration. Secrets are printed only as fingerprints.

What changed from the old version of this file
----------------------------------------------

- The **fiat on-ramp is gone.** `PENNY_ONRAMP_WALLET_BEP20` is still read by the
  admin "fund wallet via EcoCash" tool and the treasury balance display, but no
  player-facing deposit touches it. Players deposit crypto; the watcher credits
  them.
- Deposits and payouts now share **one** wallet — the agent wallet. There is no
  separate inbound address to keep topped up, because the float a player deposits
  is the float another player is paid from.
- `AURUM_BSC_RPC_URL` moved from "optional" to effectively required. Public BSC
  dataseeds refuse `eth_getLogs` outright; on them the watcher makes no progress
  and no deposit is ever credited.
- `PENNY_HOUSE_BANK_USER_ID` is no longer load-bearing. The game settles against
  the losing pool inside one mutation and takes its rake as a fee on the round —
  it no longer moves money through a house *user* row, so a missing or wrong id
  cannot silently break settlement.

Never set on production
-----------------------

- `AURUM_SANDBOX_ENABLED` — unlocks `railsSandbox.ts`, which can credit a balance
  from nothing. On this platform a credited balance walks out as real USDT.

Do not commit secrets. Set them with:

    npx convex env set NAME "value" --prod
